# 오늘얼마 — 기능 명세서 (v0.2, 2026-11-12)

> 월급날까지 하루 생존 금액 · 월급날 계산기
> 지금 잔액이랑 다음 돈 들어오는 날만 넣으면, 오늘 얼마까지 써도 되는지 알려주는 웹앱.

- 출처: 에타 댓글 "물가 때문에 하는 것도 없는데 돈이 줄줄 샘"
- 차별점: 앱 설치 없음(웹) · 지출 기록 없이 잔액 숫자 하나만 가끔 업데이트 · 1일~말일이 아니라 "내 월급날/용돈날" 기준
- 개인 프로젝트 2호 (1호: 막차 계산기)

## 2. 데이터 (기기 localStorage만)

키: `today-howmuch:v1` — 값 1개(JSON). 읽기/쓰기 모두 try/catch. 비었거나 깨졌거나 접근이 막히면 → **첫 설정 화면**.

```ts
interface AppData {
  version: 1;
  settings: Settings;
  balances: BalanceEntry[];   // [{ date, balance }] 입력한 날만. 오래된 순
}
interface Settings {
  payDay: number;              // 매달 N일 (1~31)
  earlyOnDayOff: boolean;      // "주말·공휴일이면 전날 받아요" (기본 false)
  useFixedExpenses: boolean;   // "고정 지출 빼고 계산" (기본 false)
  fixedExpenses: FixedExpense[];
}
interface FixedExpense {
  id: string; name: string; amount: number;
  paidFor: string | null;      // "나갔어요" 누른 주기(= 그때의 다음 지급일 YYYY-MM-DD). 주기가 바뀌면 자동 해제
}
interface BalanceEntry { date: string /* YYYY-MM-DD */; balance: number }
```

## 3. 기능

### F1. 첫 설정 (1회) — 11/16
- 입력: 다음 돈 들어오는 날 (매달 N일, 1~31 선택) / 지금 통장 잔액 (원, 숫자만, 천 단위 콤마)
- 체크박스 "주말·공휴일이면 전날 받아요" — 기본 꺼짐
- 스위치 "고정 지출 빼고 계산" — 기본 꺼짐. 켜면 [이름 + 금액] 항목 추가/삭제 (월세·통신비처럼 아직 안 나간 돈)
- 저장 시: settings 저장 + balances에 `{오늘, 잔액}` 1건
- 검증: 날짜 미선택·잔액 빈값이면 저장 안 함. 고정 지출 항목은 이름·금액 둘 다 있어야 저장

### F2. 계산 (순수 함수) — 11/16
- **오늘 써도 되는 돈 = (잔액 − 아직 안 나간 고정 지출 합) ÷ 남은 날수**
- 남은 날수 = 오늘부터 다음 지급일 전날까지 (오늘 포함). 예: 11/12 → 11/25 지급이면 13일
- 원 단위 내림(Math.floor) — 써도 되는 돈을 부풀리지 않기 위해
- 잔액은 **가장 최근 입력값**을 그대로 사용 (입력 안 한 날 추정 ❌)
- 0 이하면 **마이너스 그대로** 표시 (0원으로 숨기지 않음) — 결정 2026-11-12
- 고정 지출: 항목마다 **[나갔어요] 딸깍** → 이번 주기 계산에서 제외, 다시 누르면 취소. 출금일 입력은 받지 않음(귀찮음 → 앱 성격과 안 맞음). 월급날이 지나면 자동으로 다시 '아직 안 나감' — 결정 2026-11-12

### F3. 날짜 경계 — 11/16
- 오늘이 (실제) 지급일이면 → 다음 달 지급일 기준
- 그 달에 없는 날(31일·2월 30일 등) → 그 달 말일
- 옵션 ON: 토·일·**공휴일(대체공휴일 포함)**이면 직전 평일. 당겨진 날이 이미 지났으면 다음 달
- 1일 지급이 전달 말로 당겨지는 경우, 설·추석 연휴가 길게 이어지는 경우도 처리
- 공휴일 데이터: 한국천문연구원 특일 정보 API를 `scripts/fetch-holidays.mjs`로 받아 `src/lib/holidays.data.ts`에 넣어 둠 (서버 없음). 현재 **2026~2028**. 표 밖 연도는 주말만 당김. ⚠️ 임시공휴일은 발표 후 스크립트 재실행 필요
- 날짜는 기기 로컬 시간 기준, 일 단위 비교

### F4. 잔액 업데이트 — 11/17
- 바텀시트에 숫자 하나. 안내 "토스·은행 앱에 보이는 숫자 그대로"
- balances 배열에 추가. **같은 날 다시 입력하면 그날 값 덮어쓰기**(하루 1건) — 결정 2026-11-12

### F5. 지난번 대비 — 11/17
- "지난번(N일 전)보다 하루 -1,200원" = 이번 입력 기준 하루 금액 − 직전 입력 기준 하루 금액
- 입력 기준 막대 최대 5개 + 막대 아래 입력 날짜. 입력 안 한 날은 채우지도 추정하지도 않음
- 입력 1번뿐 → 점선 박스 "잔액을 한 번 더 입력하면 변화를 보여 줘요"

### F6. 메인 화면 + 상태 — 11/18
1. 헤더: "오늘얼마" + 오늘 날짜 (11.12 목)
2. 금액 카드(상태색 배경): "오늘 써도 되는 돈" + 상태 배지 / 금액 42px 굵게 #111412("원"은 작게) / 환산 한 줄(11px, 흐리게) / 마지막 입력 2일 이상 지나면 "N일 전 잔액 기준이에요 · 바꾸기"
3. 잔액 카드: "남은 잔액 · N일 전" + 금액 + [바꾸기] (터치 44px)
4. 월급날까지 카드: "13일 · 11/25" + 진행 막대(각진 끝)
5. 지난번보다 카드 (F5)

### F7. PWA · 환산 문구 · 다듬기 — 11/19
